# Zed Wasp
A [Wasp](https://wasp.sh/docs/general/language) DSL extension for [Zed](https://zed.dev/).

## Use of LLM and prior work
The important parts of this extension - the Tree Sitter grammar and syntax highlighting - were based directly on the original [VS Code extension](https://marketplace.visualstudio.com/items?itemName=wasp-lang.wasp). The grammar was translated using Google Gemini 3.5.
